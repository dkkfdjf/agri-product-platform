## 一、用户角色

| 角色 | 代码 | 权限 |
|:---|:---|:---|
| 农户 | `farmer` | 发布农产品、融资申请、专家咨询、个人中心 |
| 买家 | `buyer` | 浏览商品、下单购买、购物车、专家咨询、个人中心 |
| 专家 | `expert` | 发布知识、回答问题、查看预约 |
| 银行 | `bank` | 审批融资、智能匹配 |
| 管理员 | `admin` | 全部管理功能 |

> **角色获取方式**：农户/买家由自助注册（`POST /user/register`）获得；专家/银行由管理员添加或经"角色申请"审核开通；管理员仅由管理员添加（角色申请不允许申请 admin）。前端注册页仅提供「农户/买家」两个角色，专家/银行需先注册登录后在「个人中心 → 角色申请」提交申请。
> **个人中心入口**：farmer/buyer/expert 进入各自个人中心页；admin/bank 无个人中心页，点击头像回首页；默认头像统一为 `/images/default-avatar.png`。

## 三、API接口设计

### 基础规范
- 基础路径：`/api`
- 认证：JWT Token（`Authorization: Bearer <token>`）；白名单接口（登录/注册/公开列表/上传/静态资源）不走拦截器
- 返回格式：`{code, message, data}`
- 权限：JWT 拦截器仅验签，角色校验在各控制器内完成（如 `/admin/**` 的 `requireAdmin`）
- 基础设施：MyBatis-Plus 分页拦截器（`MybatisPlusConfig`）、全局异常处理（`GlobalExceptionHandler`，统一 `Result` 返回）、实体主键 `@TableId(type=INPUT)`（如 Expert）

### 8. 问答模块

| 方法 | URL | 说明 | 权限 |
|:---|:---|:---|:---|
| POST | `/question` | 提问（写入 questioner_real_name/expert_real_name） | farmer, buyer |
| GET | `/question/list` | 问答列表 | 所有 |
| GET | `/question/{id}` | 详情 | 已登录（提问人/专家） |

| GET | `/question/{id}/reply/list` | 追问回复列表（按时间正序） | 所有 |
| POST | `/question/{id}/reply` | 发布追问/回答（多轮对话） | 提问人追问 / 被指派专家回答 |

> **追问多轮对话**：`tb_question_reply` 存全部回复（farmer=追问 / expert=回答）；专家首条回答将 status 0→1 并刷新 `answer`（列表预览用）；status=2（结束对话）后禁止任何回复。显示姓名优先用 `*_real_name`，缺省回退账号。

### 13. 支付模块（支付宝沙箱）

| 方法 | URL | 说明 | 权限 |
|:---|:---|:---|:---|
| POST | `/alipay/pay` | 生成扫码支付二维码（当面付 alipay.trade.precreate），返回二维码链接 qr_code | buyer本人 |
| GET | `/alipay/query` | 主动查询支付结果；成功则订单 1→2 并写入 tb_payment | buyer本人 |
| POST | `/alipay/notify` | 支付宝异步回调通知（RSA2 验签；返回 success/fail） | 公开（支付宝服务器，白名单放行）|

> **公钥模式**：沙箱 AppID / 应用私钥 / 支付宝公钥 三项配在 `application-local.yml`（不入库），网关 gateway 默认值已在 `application.yml`。采用**扫码支付（precreate）**：后端返回二维码链接 `qr_code`，前端用 `qrcode` 库渲染成二维码，买家用「支付宝沙箱版 App」扫码付款；前端每 2.5s 轮询 `/alipay/query` 确认结果。本地开发无需内网穿透（`notify_url` 仅生产环境生效）。商户订单号 `out_trade_no` 直接复用 `purchase_id`，回调据此反查订单并幂等落库。

## 四、状态值规范

| 类型 | 值 | 说明 |
|:---|:---:|:---|
| 通用开关 | 0/1 | 0关/禁用 1开/正常 |
| 订单状态 | 1-5 | 1待付款 2待发货 3待收货 4已完成 5已取消 |
| 融资状态 | 0-2 | 0申请中 1已通过 2已驳回 |
| 问答状态 | 0/1/2 | 0未回答 1已回答 2已关闭（结束对话，禁止再回复） |
| 预约状态 | 0-2 | 0待处理 1已完成 2已拒绝 |
| 角色申请状态 | 0-2 | 0待审核 1通过 2驳回 |

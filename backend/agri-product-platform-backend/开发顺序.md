## 🚀 阶段一：基础搭建（第1周）

**目标**：搭建开发环境，完成登录注册功能

### 第1-2天：环境搭建

| 任务 | 负责人 | 说明 | 产出 |
|:---|:---|:---|:---|
| 数据库创建 | 项目经理 | 导入SQL，配置MySQL | 可用的数据库 |
| 后端项目初始化 | 吴金磊 | SpringBoot项目框架 | 可运行的后端空项目 |
| 前端项目初始化 | 颜达 | Vue3项目框架 | 可运行的前端空项目 |
| 确定接口规范 | 全员 | 统一API返回格式、JWT规范 | 接口文档模板 |

**前置条件**：
- 已安装：JDK 17+、Node.js 18+、MySQL 8.0、IDE（IntelliJ IDEA + VSCode）

### 第3-5天：登录注册功能

| 任务 | 负责人 | 说明 | 产出 |
|:---|:---|:---|:---|
| 后端-用户实体类 | 吴金磊 | User实体、UserMapper | User.java |
| 后端-注册接口 | 吴金磊 | POST /api/user/register | 注册API |
| 后端-登录接口 | 吴金磊 | POST /api/user/login + JWT | 登录API |
| 后端-拦截器配置 | 吴金磊 | JWT认证拦截器 | 认证框架 |
| 前端-登录页面 | 颜达 | 登录表单、样式 | Login.vue |
| 前端-注册页面 | 颜达 | 注册表单、样式 | Register.vue |
| 前端-路由配置 | 颜达 | 配置路由、导航守卫 | router配置 |
| 前端-状态管理 | 颜达 | Pinia用户状态 | store/user.js |
| 前后端联调 | 吴金磊+颜达 | 测试登录注册流程 | 可正常登录注册 |

**完成标志**：
- ✅ 用户可以注册新账号
- ✅ 用户可以登录并获取Token
- ✅ 登录后可以访问需要认证的页面

## 🔥 阶段二：核心功能开发（第2-4周）

**目标**：完成各模块功能，三人并行开发

### 开发策略

- **依赖关系**：各模块相对独立，可以并行开发
- **接口约定**：前端先用Mock数据开发，后端提供接口后联调
- **每日同步**：每天晚上同步进度，解决接口问题

---

### 👨‍💻 项目经理任务（2个模块）

#### 模块1：专家助力模块（第2周）

**顺序**：

```
第1天：农业知识功能
  ├─ 后端：知识列表API、详情API、发布API、评论API
  └─ 前端：知识列表页、知识详情页、发布知识页

第2天：问答功能
  ├─ 后端：问答列表API、提问API、回答API
  └─ 前端：问答列表页、提问页、专家回答页

第3-4天：专家功能
  ├─ 后端：专家列表API、专家详情API
  └─ 前端：专家列表页、专家详情页

第5天：专家预约功能
  ├─ 后端：预约API、预约列表API、处理预约API
  └─ 前端：预约表单页、我的预约页、专家预约管理页
```

**涉及表**：
- tb_expert（专家表）
- tb_knowledge（知识表）
- tb_discuss（评论表）
- tb_question（问答表）
- tb_reserve（预约表）

**涉及API**（11个）：
```
GET  /api/knowledge/list          # 知识列表
GET  /api/knowledge/{id}          # 知识详情
POST /api/knowledge               # 发布知识（专家）
POST /api/knowledge/{id}/discuss  # 评论知识
GET  /api/knowledge/{id}/discuss/list  # 评论列表

GET  /api/question/list           # 问答列表
POST /api/question                # 提问
PUT  /api/question/{id}/answer    # 回答（专家）

GET  /api/expert/list             # 专家列表
GET  /api/expert/{username}       # 专家详情

POST /api/reserve                 # 预约专家
GET  /api/reserve/list            # 我的预约
GET  /api/reserve/expert/list     # 专家的预约（专家）
PUT  /api/reserve/{id}/status     # 处理预约（专家）
```

# 轮播图管理
GET    /api/banner/list          # 轮播图列表
